# Portofolio Rylianicha

Website portofolio pribadi sederhana menggunakan HTML dan CSS.

## Isi folder
- `index.html` — halaman utama beserta CSS responsif
- `assets/foto-rylianicha.png` — foto profil

## Cara melihat di komputer
1. Ekstrak folder ZIP.
2. Buka folder di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.

## Cara mengunggah ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html` dan folder `assets` (jangan hanya mengunggah file HTML).
3. Buka **Settings → Pages**.
4. Pada bagian build/deployment, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan.
5. Tunggu proses publikasi selesai; GitHub akan menampilkan alamat website.
